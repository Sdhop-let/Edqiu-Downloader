# releases/ · 按版本归类的发布说明

> 每个子目录对应一个发布版本，命名：`v<主>.<次>.<修订>/`。
> 目录内 `RELEASE-NOTES.md` 记录该版本元数据（versionCode、构建日期、APK MD5）与变更内容。
>
> - **APK 二进制不进入 git 仓库**（避免仓库膨胀），一律通过 [GitHub Releases](https://github.com/Sdhop-let/Edqiu-Downloader/releases) 的资产下发
> - 全版本时间线见根目录 [CHANGELOG.md](../CHANGELOG.md)
> - 更早版本的说明（v1.2.x ~ v1.3.0）位于 [`docs/`](../docs/) 下的 `RELEASE_NOTES-*.md` / `CHANGELOG-*.md`
