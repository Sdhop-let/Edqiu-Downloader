## 浏览模式（2026-11-07 定案）

- 冷启动新增浏览模式选择（也可在 设置 · 外观 中更改，可勾选「不再每次询问」记住选择）：
  - **标准模式**：媒体正常显示（默认）
  - **隐私模式**：视频/图片全量模糊防偷看，按住可临时查看——Android 12+ 真高斯模糊（28dp），低版本自动回退表面色蒙层 +「已隐藏」标识
- 模糊覆盖全部媒体展示面：收件箱卡片、详情大图、媒体库封面、下载页、作者页、备份页、播放器抽屉与播放画面
- 隐私模式下播放器不起播：封面模糊常驻，按住画面才播放（松手暂停），二次防护
- 进入隐私模式时底部胶囊提示「媒体已模糊，按住可临时查看」
- 模式选择器排版重整：双卡等高对齐、「上次选择」外置单行完整显示、底部导航栏避让（3-button 导航设备）

## WebDAV 整传治理（2026-11-03）

- **城通网盘「假失败」修复**：PUT 专用客户端放宽超时（共享连接池）+ 全部尝试耗尽后终局 HEAD 复核成品是否已落地——网关收完大文件 body 后响应超时的误报失败不再触发重传
- **详情页「停止本轮」**：随时中断当前同步轮，已传部分保留（非失败态，防用户遗忘的当轮生效）
- **per-file 隔离**：单文件传输失败不再中断整轮，本轮结束汇总跳过数，下轮自动续传

## 捕获链路增强（2026-11-04）

- **剪贴板多形态读取**（小米 12 Pro / HyperOS 机型适配）：多条目 ClipData / Intent 条目（coerceToText 编码串）/ HTML `<a href>` / URI 条目 / 整体 URL 编码正文全覆盖
- **t.co 短链展开兜底**：正文找不到 status 链接却存在 t.co 短链时才走网络展开（GET 跟随跳转，逐条 2.5s 限时、最多 3 条，失败静默回退原文——离线捕获语义不破坏）
- **链接解析容错**：裸链识别（`x.com/user/status/123` 不带 scheme 也认）+ 零宽不可见字符清洗（U+200B-U+200D / U+FEFF / U+2060）
