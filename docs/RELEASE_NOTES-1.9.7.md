# v1.9.7 更新内容

**主题：媒体库重做（下载时间排序 + 双列封面网格）· 渲染冻结根治 · 开屏后帧源治理**　versionCode 56

## 媒体库 · 全面重做

- **排序改为下载时间（默认）**：刚下完的在最上——旧版按发布时间排序，今天下载的老作品会沉到很下面（不是 bug，是旧设计与直觉相悖，本次纠正）。点「按下载时间 ⇄ 按发布时间」胶囊随时切换，选择会记住；发布时间模式下保留原「作者 · 发布日」分组
- **下载日分组**：开「作品分组」后按 今天 / 昨天 / 具体日期 分段，最新一天在最上
- **双列封面网格（全新卡片方案）**：旧的全宽大卡（一屏仅 2 条）换成作品墙——方形大封面 + 中央播放钮 + 时长角标 + 作者·画质一行，一屏可见 4-6 条；分享/删除在封面右上角菜单，删除确认保留
- **筛选固定在标题下**：全部 / 视频 / 图片 计数胶囊固定在标题正下方，滚动不离开
- **顶部重排**：标题行只留 搜索 + 刷新 两个按钮；升级（画质）入口与排序/分组/查重聚到列表首行操作条，文字与按钮不再拥挤
- 性能实测：网格滚动 jank 1.54%——全项目历史最佳

## 渲染冻结根治（历史遗留难题结案）

- 间歇性「画面冻在半路」的根因链完整闭合：无限动画让应用持续出帧不空闲 → 系统推迟前页 STOP 提交（实测延迟约 20 秒）→ 迟到的生命周期事务与主界面切换乱序 → 窗口被错误标记为不可见（停止绘制）
- 三处持续帧源全部封顶：开屏动画一次性化（1.9.6）、加载骨架扫光限时 2.5 秒、定位高亮脉冲限时 3 秒
- 实测结案证据：STOP 延迟从约 20 秒降至 0.39 秒；13 轮冷启动+快速开浮层锤炼零冻结
- 自愈升级：万一未来再触发，3.6 秒内自动恢复且**正在看的浮层原样恢复**（此前会丢失浮层状态）
