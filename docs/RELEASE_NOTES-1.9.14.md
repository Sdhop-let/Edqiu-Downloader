# v1.9.14 更新内容

**主题：文字可读性总根源修复——任意壁纸下文字均清晰**　versionCode 63

## 修复

- **浅色主题壁纸压白层 0.18→0.35（总根源）**：0.18 时壁纸照片近乎裸奔（亮暗区并存），任何固定字色都会在某类壁纸区域失效——灰字、青字看不清的总根源。0.35 白把舞台压成稳定浅色衬底：文字（黑/灰/绿）在**任意壁纸**下均可读，壁纸细节仍清晰可辨、玻璃折射不受影响
- **玻璃卡面加白（浅色主题 +0.12）**：卡片上的灰字/正文获得稳定浅色衬底——壁纸暗区透过薄卡面导致深灰字不可读的问题一并解决；壁纸仍透出 50%+
- 深色主题不变（黑 scrim 下浅字对比本就充足）

## 兼容性

- 数据库版本不变（v15/v11），覆盖安装数据全保留
- Android 7.0+（API 24）· 仅 arm64-v8a
