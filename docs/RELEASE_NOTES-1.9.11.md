# v1.9.11 更新内容

**主题：签名密钥更换（安全整顿）——旧版无法覆盖升级，务必先备份再卸载重装**　versionCode 60

## ⚠️ 本次升级方式特殊（必读）

本版起应用改用**全新正式签名密钥**（旧版沿用开源模板的弱口令调试密钥，存在被伪造冒用的风险）。Android 不允许跨签名覆盖安装，因此：

1. **卸载前**：打开「备份中心 → 网盘同步」确认已完成**全量备份**（媒体文件全部上传）；「数据备份」导出收件箱 JSON 并妥善保存
2. **卸载旧版**（卸载会清空应用数据与下载目录，媒体以网盘备份为准）
3. **安装本版**（需重新允许「安装未知来源应用」）
4. **恢复**：配置 WebDAV 后双向同步把媒体拉回（媒体库自动重建）；「数据备份」导入收件箱 JSON
5. **重配**：X Cookie / 代理 / 玻璃外观参数；订阅作者需重新添加（订阅列表不在备份范围）

## 变更

- **签名密钥更换**：XInvox 时代 debug-fixed 弱口令密钥（密码即 `android`）退役，启用 2026-10 生成的正式密钥（RSA 4096 + SHA256withRSA，证书 SHA-256 `E8:05:B0:01:…:39:1A`）
- 功能与 v1.9.10 完全一致，无功能变更

## 兼容性

- 数据库版本不变（v15/v11）
- Android 7.0+（API 24）· 仅 arm64-v8a
