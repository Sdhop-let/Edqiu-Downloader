# v1.9.1 更新内容

**主题：设计系统组件化收尾——输入场与多选控件全面统一**　versionCode 50

## 统一 iOS 输入场（27 处全量迁移）

- 新增统一输入场组件：iOS 填充式风格（浅灰圆角填充面，常态无边框），聚焦时填充提亮一档并浮现强调色细描边，光标走强调色
- 标签改为场外上方独立小字（iOS 分组表单语言），替代 Material 浮动标签
- 全应用 27 处输入框统一换装：设置页（下载路径 / 代理 / Cookie / 第三方 API / WebDAV / 攒批条数等 17 处）、首次引导（Cookie 与代理配置 4 处）、云备份（WebDAV 表单与网盘授权 5 处）、收件箱粘贴捕获框与媒体库搜索框
- 收件箱顶部「粘贴链接」输入条同步统一
- Material 描边框输入样式全面退场

## 多选勾选圆圈（iOS 风）

- 收件箱批量管理模式的勾选框替换为 iOS 风勾选圆圈：未选中为中性描边空心圆，选中为强调色实心圆 + 白勾弹性出现
- 无障碍语义与原勾选框一致（读屏行为不变）；系统「减少动画」开启时跳变呈现

## 仓库清理

- 移除三个无调用死组件与遗留死导入（界面行为零变化）
- 新增设计验收清单（`docs/design/AUDIT-CHECKLIST.md`）：设计令牌速查 + 发布前逐项走查表

## 兼容性

- 全部既有设置与数据不变；多选、粘贴捕获、WebDAV 配置等业务逻辑零改动
- 旧版本可直接覆盖安装
