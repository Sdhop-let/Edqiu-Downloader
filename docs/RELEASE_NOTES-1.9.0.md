# v1.9.0 更新内容

**主题：固定 iOS 式配色 + 大标题折叠体系（全量 UI 重构）**　versionCode 49

## 配色体系重构

- 壁纸取色 / 系统 Monet / 派生引擎全部移除——壁纸变化不再影响任何界面颜色
- 新配色 = 固定 iOS 式中性面（浅色清透白 / 深色石墨黑）+ 单一强调色 tint（默认 iOS 蓝）
- 强调色只作用于按钮、开关、选中态与玻璃染色，不改变背景与界面层次
- 派生改为固定映射规则：深色模式 tint 自动提亮、容器色线性混色、onPrimary 按亮度取黑白——预设与自定义色一视同仁，效果可预测
- 强调色预设换 iOS 系统调色板 12 色（蓝/青绿/薄荷/靛紫/紫/粉/橙/琥珀/黄/绿/莓红/石墨），自定义 HSV 取色保留
- 状态语义色统一 iOS 系统色（橙=未下载、绿=已下载、红=失败、灰=已删除）
- 修复：设置页标题在深色模式下不可读的遗留问题
- 开屏改 iOS 惯例：中性背景 + 强调色品牌字

## 大标题↔紧凑导航折叠

- 收件箱 / 下载中心 / 回收站 / 网盘备份 / 媒体备份：列表滚动时大标题平滑收缩为紧凑导航标题，副标题淡出
- 列表内大标题页滚动后顶部淡入紧凑导航条（iOS「large title scrolls away」行为），下载中心/回收站补齐常驻返回钮

## 页面统一

- 回收站整体重写：最后一处 Material 原生形态（TopAppBar/BottomAppBar/默认卡片）退场，改玻璃卡片 + 玻璃批量操作条
- 统一分段胶囊替代全部 Material FilterChip（备份范围/媒体类型/画质/自动备份频率/攒批条数）
- 统一 iOS 滑杆（细圆角轨道 + 白色带影拇指 + 拖动增强）替换设置页全部参数滑杆
- 全部进度条统一 6dp 圆角胶囊；空态图标底改主题容器色；详情页头像兜底色/圆钮底色统一

## 播放器与动画

- 播放/暂停图标交叉淡入平滑转换
- 进度条拖动视觉增强：按下时拇指放大、轨道增粗，松手平滑回落；拖动期只更新本地进度、松手才跳转的防抖逻辑保留
- 全局按压反馈增加轻缩放（系统「减少动画」开启时自动降级为纯触感）
- 新增全局动画令牌表，核心组件动画参数单一来源

## 兼容性

- 玻璃三滑块（透明度/磨砂/折射）、玻璃外观四项（描边/亮边/描边色/压暗）、液态玻璃开关、界面缩放、高刷新率、触感档位等全部既有设置保留不变
- 旧数据无缝升级：强调色沿用原存储值，默认值变更只影响新安装
