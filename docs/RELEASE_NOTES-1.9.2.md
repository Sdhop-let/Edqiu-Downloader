# v1.9.2 更新内容

**主题：WebDAV 同步重构 + 真正作品订阅 + 设置页信息架构重做**　versionCode 51

## WebDAV 同步重构

- **网盘备份中心整体移除**（BackupEngine 队列 / 多网盘适配器 / 备份账本）：WebDAV 同步页即唯一的配置与同步入口，同步幂等改由「远端尺寸对账」天然保证
- **每网盘独立账号配置**：每个预设（123网盘 / 城通 / CloudDrive2 / 坚果云 / 自定义…）的地址、账号、密码（KeyStore 加密）、远程目录、验证结论独立存储——切换预设互不覆盖、互不串号；旧配置自动迁移
- **保存语义**：仅「测试连接」成功时保存该网盘配置与验证结论，失败一律不落盘；删除 600ms 去抖自动落盘，杜绝「页面显示新值、同步跑旧值」
- **同步情况详情页重做**：「同步 | 已同步」双分页；本地 × 远端逐文件对账（已同步 / 待上传 / 冲突三态）；**正在同步的文件高亮置顶**（单项进度条 + 百分比）；待上传条目支持**逐个 ⏸ 暂停 / ▶ 恢复 / ⬆ 置顶优先**（暂停对传输中的大文件立即生效，`.edqiu-part` 断点保留）
- **传输可靠性**：上传对账改为单次 PROPFIND 后内存比对（修复「无法确认远程文件状态」中断整轮——高频 HEAD 触发网盘限流）；瞬态错误（408/429/5xx）指数退避重试；**对账双名兼容**——早期版本上传的纯文件名存量不再被误判「未同步」；断点续传重构为每轮重试重新探测 `.part` 实际进度（支持 PATCH 追加的服务器从断点续传）；连接池保活 90s（消除文件间 TLS 重握手卡顿）
- **页面不透明全屏化**：详情页不再透出底部 Tab 栏
- 手动同步与自动备份共用运行令牌，杜绝并发双传；同步轮结束自动清空暂停/优先控制

## 真正作品订阅

- **作品订阅独立二级菜单页**：订阅列表（平台徽标 / 启停开关 / 上次检测与上次发现时间 / 逐条检测）+ 手动添加（handle + 平台）+ 「立即检测全部」
- **双端一键订阅**：作者中心卡片「订阅作者」按钮；播放器作者行常驻订阅铃铛（原 ⋮ 菜单入口保留，状态联动）
- **多平台检测**：X（yt-dlp 用户页）/ **Bluesky**（公共 AppView API，无需登录）/ Instagram（yt-dlp，实验性）
- **闭环**：后台每 25 分钟轮询（最旧优先 3 作者/轮，每作者每轮最多 3 条防风控），发现新作品自动加入收件箱并走下载链自动下载；检测结果可视化（上次检测 / 上次发现时间）

## 设置页信息架构重做

- 「我的」页改为**六张领域卡**（卡即分组，去除组标题套同名卡的冗余层级）：作品库 / 订阅与自动化 / 网络与同步 / 外观与播放 / 存储与备份 / 通用——全部入口与描述重新命名
- 作品订阅归入「订阅与自动化」；卡间分隔线移除、间距统一 12dp（iOS 分组卡节奏）
- 玻璃卡下沉到卡级：每张领域卡独立 L1 玻璃（含「关于本机」），与全页玻璃体系完全统一

## 兼容性

- 存量订阅与网盘配置自动迁移（订阅表新增 platform 列，检测库 v12；主库 v10 移除备份账本表）
- 网盘备份中心功能移除，其配置随功能失效——WebDAV 同步页是唯一入口
- 旧版本可直接覆盖安装；全部既有下载数据不变
