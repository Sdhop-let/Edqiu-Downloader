# v1.9.5 更新内容

**主题：壁纸舞台真玻璃 · 顶栏重构（iOS large title）· 下载状态与媒体库重复双修复**　versionCode 54

## 液态玻璃 · 壁纸舞台落地

- **背景接真实壁纸**：玻璃直接折射你的系统壁纸——壁纸 28dp 高斯虚化铺底（半尺寸降采样省内存、后台线程加载、进程级缓存），玻璃的磨砂与折射第一次作用于真实照片而非程序化色板；壁纸加载失败自动降级为色场，观感无缝回退
- **底栏透字完全体**：底栏玻璃为半透明捕获，滚动中的卡片文字与壁纸从玻璃后透出（网易云式透字）；底栏轻磨砂固定 8dp——文字轮廓可辨与磨砂质感的平衡点；底栏去掉外圈描边，一枚干净的玻璃胶囊
- **卡片玻璃化**：卡片底色透明度升档 + 描边/顶光减半——壁纸的光与色彩透过卡片上来，每张卡片背后透出的明暗都不同；玻璃退到氛围层，内容成为主角
- **色场重做**：砍掉全屏平铺染色（旧版整屏被强调色染透的根因），换「中性基底 + 局部光斑团」；壁纸模式下光斑减半只作色彩氛围
- **磨砂恢复真高斯**：「ColorOS 离屏白框」归因经 debug 构建四用例实机判决证伪（该白框实为 Compose blur 边缘处理用法问题），磨砂层恢复真 RenderEffect 高斯（8-36dp 随磨砂强度）

## 顶栏重构（收件箱 / 媒体库对称，iOS large title 语义）

- **收件箱**：统计卡与搜索框移入列表随内容滚走，筛选行 sticky 吸顶常驻（去外部长方形包围，胶囊直接浮在壁纸上）；大标题区滚动时空间真正折叠（此前只缩字号不收空间）
- **媒体库**：新增固定标题条（E 徽章 + 标题 + 数据副行 + 升级/搜索/刷新），数据副行随滚动折叠收零；搜索条/视图行/筛选数据卡随内容滚走
- **边缘软着陆**：列表顶部 24dp / 底部 24dp 三段缓曲线渐隐带——卡片撞顶撞底不再硬切，被背景色调渐变温柔接住
- **移除底部渐隐擦除带**：旧「内容化开」效果把滚入底栏前的内容擦成透明，透字素材被其吃掉——拆除后内容真实滚入底栏玻璃后面

## 下载状态修复

- **点按即刻反馈**：引擎链启动期（API 分析 + yt-dlp 初始化可达 5-10 秒）内收件箱卡片不再毫无变化——点下载瞬间显示「下载中 0%」，引擎接管后实时推进度
- **失败原因写在卡片上**：下载失败的卡片直接显示引擎链失败详情（哪层引擎、什么原因），弹窗同步完整信息
- 多任务进度归并由均值改为取最大——占位任务不再把真实进度拦腰砍半

## 媒体库重复根治 + 状态自愈

- **重复入库根治**（DB 实证 394+391 行重复 → 392 行零重复）：媒体库记录 id 移除画质字段（画质升级 + 扫描竞态下同文件被解析成不同 id）；清理逻辑按**不区分大小写的文件路径**去重——历史扫描用 `com.ed.edqiu` 小写、当前用 `com.ed.Edqiu` 大写，同一物理目录被当成两批文件全量重复入库，本次一并清理
- **状态自愈**：后台同步降级前先查媒体库（监控目录没扫到 ≠ 文件不存在）；未下载条目每轮自动与媒体库比对回写「已下载」——不再出现「媒体库有文件、收件箱却显示未下载」

## 其他

- 实验性构建源集 `app/src/debug/`（液态玻璃渲染判决实验页）仅存在于 debug 构建，release 不受影响
