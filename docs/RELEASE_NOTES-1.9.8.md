# v1.9.8 更新内容

**主题：订阅治理（只收订阅作者本人作品 + 不再重复拉取）· 更新安装体验修复**　versionCode 57

## 作品订阅 · 两大问题修复

- **只收订阅作者本人的作品**：此前检测通道会把时间线里的**转推/引推**（原创者是别人）也无差别收进订阅作品——你没订阅的作者的作品就是这么混进来的。现在 X 检测逐条校验推文作者与订阅 handle 一致，Bluesky 跳过全部转推条目；作者信息缺失的条目保守放行不误杀
- **不再每日重复拉取**：你在订阅页删过的作品，此前下一轮检测（每 25 分钟）又会原样捞回来——每天"检测出新作品"的重复视频/图片就是它。现在捕获前同时查收件箱与回收站，已删作品永不复活（与媒体库扫描同一条「防删除复活」铁律）
- 实测验证：存量订阅全量检测一轮，「暂无新作品」——转推与已删条目全部正确过滤

## 更新安装体验修复

- **授权返回后自动继续安装**：此前下载完点安装 → 跳去开「未知来源安装」权限 → 返回 App 后安装入口丢失，只能重新下载 74MB。现在权限开启返回「更新与工具」页时自动拉起系统安装器，继续完成安装
- **同版本安装包复用**：已下载且完整性校验通过（版本 + 签名双校验）的安装包直接复用，不再删掉重下；损坏/半截包才自动重新下载

## 兼容性

- 数据库版本不变（v15/v11），覆盖安装数据全保留
- Android 7.0+（API 24）· 仅 arm64-v8a
