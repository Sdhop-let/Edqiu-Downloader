# v1.9.10 更新内容

**主题：下载时直接拉 HLS 高画质（对齐画质升级器条件）**　versionCode 59

## 下载期 HLS 直拉放宽

- **此前**：只有「FXTwitter 标记了 HLS 流 且 mp4 最高码率 <2Mbps」才在下载时转 yt-dlp 拉 HLS——但 FXTwitter 的 HLS 标记经常缺失，大量 ≤720p 视频先落盘低清文件、再靠后台画质升级器二次下载（重复流量 + 等待）
- **现在**：对齐画质升级器的激进档——**已配置 X Cookie 时，最高 mp4 不足 2Mbps（约 720p 以下）的视频一律直接转 yt-dlp 拉取 1080p+ HLS，一次到位**
- **保底链**：yt-dlp 拉流失败（无 HLS / 登录失效 / 网络问题）自动回退内部引擎直下 mp4——「拉不到最高画质」不会变成「什么都拿不到」；用户主动取消不被回退覆盖
- **守卫**：纯图片推文不路由（无流可拉）；16KB 内存页机型（ffmpeg 不可用）不路由；回退通道禁用二次路由防死循环

## 兼容性

- 数据库版本不变（v15/v11），覆盖安装数据全保留
- Android 7.0+（API 24）· 仅 arm64-v8a
- 前置条件：在「网络连接」配置 X Cookie 后，低画质视频即走 HLS 直拉；未配置 Cookie 时行为与旧版一致
