## 🆕 新增功能

### 1. 推文不存在终态（DELETED 状态）
- 新增 `LinkStatus.DELETED`：推文已被删除/不存在时进入**永久终态**，不再反复重试。
- 触发链路：FXTwitter 返回 HTTP 404 或 JSON `code=404` → 抛出 `TweetGoneException` → 跳过 yt-dlp 回退 → 标记「推文不存在」并清空下次重试时间。
- UI：卡片/徽标灰色「推文不存在」，详情页下载按钮禁用、失败原因灰色显示（非红色）。
- 失败页统一收纳 FAILED + DELETED，可一键清理。

### 2. 视频首帧预览图（同步情况页）
- 资源备份列表中，本地视频文件直接用 **Coil `VideoFrameDecoder` 解码视频首帧**作为缩略图，一眼区分视频内容。
- 解码失败（无帧/损坏）自动回退电影图标。
- 页面级复用同一 `ImageLoader`，避免每个列表项重复创建加载器，滚动更流畅。

### 3. 下载结果弹窗（替代 Snackbar）
- 单个/批量下载结果改为居中 **AlertDialog「下载结果」**，批量模式展示 成功 / 失败 / 跳过 数量统计。

### 4. 批量下载预览弹窗
- 收件箱批量下载前弹出预览，横向缩略图列表（有封面显示封面，无封面显示占位图标），确认后执行下载。

## ⚙️ 优化

- **同步情况页 Tab 均分铺满**：视频/图片筛选 Chip 均分整行宽度，右侧「同步」按钮固定宽度，布局更整齐。
- **自动重试隔离**：`getRetryableFailures` 只查 FAILED、预下载只查 PENDING，DELETED 天然不参与，无需额外过滤逻辑。
- **屏幕旋转行为**：普通页面跟随系统自动旋转；`PlayerScreen` 全屏锁横屏（`SENSOR_LANDSCAPE`），退出恢复竖屏；旋转过渡 `CROSSFADE` 平滑、不重建 Activity。
- **数据库兼容**：新增枚举值无 migration 风险（`Converters.toStatus` 对未知值容错为 PENDING）。
