# XInvox Liquid Glass × Monet 界面设计方案

> 日期：2026-08-01
> 范围：全新 UI 设计语言 —— 实时模糊毛玻璃 + 莫奈动态取色 + 液态胶囊底部导航 + 动态开关 + 播放器实用化重构
> 技术栈：Kotlin 2.0.21 / Jetpack Compose / Material 3 / Media3 ExoPlayer / Coil
> 约束：minSdk 24 / targetSdk 34 / 不改变任何下载、捕获、持久化逻辑

---

## 1. 设计理念：Glass You

本次改版的核心命题是**两种设计语言的融合**：

| 来源 | 提供什么 | 在本案中的角色 |
|---|---|---|
| **Material You / Monet** | 动态取色系统（tonal palette） | 色彩的主权——颜色跟随壁纸呼吸 |
| **Apple Liquid Glass**（iOS 26/27） | 液态玻璃材质语言 | 质感的主权——实时模糊、折射高光、边缘光 |

一句话定位：**用莫奈的色彩给液态玻璃上色，用液态玻璃的材质承载莫奈的色彩。**

三条不可动摇的原则：

1. **功能零损失**——播放器、下载、捕获、搜索、批量等既有交互一个不删
2. **色彩动态化**——主色从壁纸提取（Android 12+），系统提供降级种子色
3. **性能有底线**——毛玻璃分级渲染，低端机自动降级为"半透明+高光"模拟，绝不阻塞主线程

## 2. 色彩系统：Monet Tonal System

### 2.1 取色架构

```
系统壁纸 → Monet 引擎 → 5 个 tone 组（primary/secondary/tertiary/neutral/neutralVariant）
                              ↓
            动态映射到 M3 ColorScheme（API 31+）
                              ↓
            低于 API 31 → 降级为静态种子色方案（品牌墨蓝 #2F4C8F）
```

**取色优先级**（可配置）：

| 优先级 | 种子来源 | 说明 |
|---|---|---|
| 1（默认） | 系统壁纸动态取色 | Android 12+，跟随壁纸自动变化 |
| 2 | 用户手动覆盖 | 设置页内置 6 组种子色预设 |
| 3 | 降级静态色 | API < 31 或取色失败时的品牌色 |

### 2.2 种子色预设（fallback 与手动覆盖）

| 预设 | 种子色 | 氛围 |
|---|---|---|
| 墨蓝（品牌默认） | `#2F4C8F` | 沉稳、专业 |
| 曜石黑 | `#101417` | 极简工具感 |
| 珊瑚橙 | `#E8583A` | 活力、热情 |
| 抹茶绿 | `#3E7C4F` | 清新、柔和 |
| 薰衣草紫 | `#7C5CBF` | 优雅、创意 |
| 玫瑰粉 | `#C45B7E` | 温柔、私密 |

### 2.3 Tonal Palette 语义映射

莫奈取色产出的 5 组 tone 直接映射 M3 语义角色：

| M3 角色 | Monet Tone 组 | 用途 |
|---|---|---|
| `primary` | primary（40 / 80） | 主按钮、选中态、强调 |
| `secondaryContainer` | secondary（90 / 30） | 次级容器、chip 选中底 |
| `tertiaryContainer` | tertiary（90 / 30） | 播放器强调、FAB |
| `surface` | neutral（98 / 6） | 页面基底 |
| `surfaceContainer` | neutral（94 / 12） | 卡片、底栏容器 |
| `surfaceContainerHigh` | neutral（92 / 17） | 浮层、弹窗 |
| `onSurface` | neutral（10 / 90） | 主文本 |
| `outline` | neutralVariant（50 / 60） | 描边 |

### 2.4 状态语义色（收件箱专用，固定不跟随壁纸）

下载状态必须跨主题可辨识，**锁定为固定色**（含暗色变体，取自现有 `Color.kt`）：

| 状态 | 亮色 | 暗色 |
|---|---|---|
| PENDING 待下载 | `#B45309` 琥珀 | `#E0C8A8` |
| DOWNLOADED 已下载 | `#087251` 绿 | `#6EE7B7` |
| FAILED 失败 | `#B91C1C` 红 | `#FFA39E` |

> 设计决策：状态色不做动态化——`语义可辨识性 > 视觉统一性`。状态点同时用形状辅助（圆形=待、对勾=已、叹号=败），不依赖颜色单通道。

### 2.5 玻璃上的色彩规则

毛玻璃会降低下层色彩的饱和度，因此：

- 玻璃表面上的**强调元素**（按钮、开关、胶囊选中态）一律使用 `primary(40)` 全饱和色，不用半透明 primary
- 玻璃表面上的**文本**用 `onSurface` 全不透明，避免 90% 以下透明度叠加模糊产生糊感
- 高光描边统一用 `white 40%`（亮色） / `white 12%`（暗色）

## 3. 材质系统：三层玻璃

### 3.1 玻璃分层

```
┌─────────────────────────────────────────┐
│  L0 背景层  —— 壁纸 / 动态渐变色域        │  ← 唯一的"实心"层
├─────────────────────────────────────────┤
│  L1 页面层  —— 列表、卡片所在区域          │  ← 大面玻璃，重透
│    卡片 = 玻璃上的玻璃（双重模糊）          │
├─────────────────────────────────────────┤
│  L2 浮层    —— 底部导航栏、播放器控制层     │  ← 悬浮玻璃，重模糊
├─────────────────────────────────────────┤
│  L3 弹出层  —— BottomSheet、Snackbar      │  ← 最高层玻璃
└─────────────────────────────────────────┘
```

### 3.2 玻璃参数规格（亮色 / 暗色）

| 参数 | L1 页面层 | L2 浮层 | L3 弹出层 |
|---|---|---|---|
| 背景色 | `neutral 94%` | `neutral 92%` | `neutral 90%` |
| 背景不透明度 | 55% | 65% | 78% |
| 模糊半径 | 24px | 40px | 48px |
| 饱和度增强 | +10% | +15% | +20% |
| 高光描边 | white 35% / 1px | white 45% / 1.5px | white 50% / 1.5px |
| 暗色不透明度 | 40% | 50% | 62% |
| 暗色描边 | white 8% | white 10% | white 12% |

### 3.3 性能分级（关键决策）

实时模糊在低端机上是性能陷阱，采用 **Tier 分级**：

| Tier | 判定 | 行为 |
|---|---|---|
| Tier A | API 31+ 且无动画中 | 全量实时模糊（RenderEffect） |
| Tier B | API < 31 或低内存 | 半透明 Surface + 高光渐变模拟玻璃（无真实 blur） |
| Tier C | 滚动/转场动画进行中 | 模糊降级为上一帧缓存（静态模糊），动画结束后恢复 |

> 实现要点：模糊用 `Modifier.blur()` 或 `graphicsLayer { renderEffect = BlurEffect() }`；Tier 判断封装为 `GlassSurface` 组件内部逻辑，业务代码零感知。

### 3.4 玻璃边缘光（Liquid 灵魂）

每块玻璃边缘加 **1.5dp 内高光**：顶部亮（模拟光线折射），底部暗。用渐变 `Brush.linearGradient` 实现，视觉上让玻璃"鼓起来"。

## 4. 液态胶囊底部导航（Liquid Capsule Tab Bar）

### 4.1 视觉规格

- **容器**：L2 浮层玻璃，`surfaceContainerHigh` 底，圆角 **28dp**，水平 16dp 悬浮间距，底部 12dp 安全区
- **高度**：64dp（含 8dp 呼吸内边距）
- **选中态**：液态胶囊——`primary(40)` 全饱和渐变填充 + 2dp 内高光 + 弹性放大（scale 1.06）
- **未选中态**：`onSurfaceVariant` 图标 + 标签，无容器
- **图标**：28dp 线性图标，选中时**图标填充变化**（linear → rounded），实现"胶囊内有光"

### 4.2 动效规格

| 动效 | 时长 | 曲线 |
|---|---|---|
| 胶囊形态变换（圆角→椭圆鼓胀） | 300ms | `Spring(dampingRatio=0.6, stiffness=320)` |
| 选中图标填充切换 | 240ms | `FastOutSlowInEasing` |
| 标签显隐（选中才显示标签） | 200ms | `FastOutSlowInEasing` |
| 未选中图标位移（向胶囊聚拢） | 280ms | `Spring(0.7, 280)` |

### 4.3 结构

```
[ 收件箱 📥 ]  [ 回收站 ♻ ]  [ 设置 ⚙ ]     ← 三 Tab（保持现状）
```

- 播放器/详情页全屏时**隐藏**底栏
- 播放器内嵌模式（迷你播放条）时底栏**让位**：播放条浮在底栏上方

## 5. 动态开关（Dynamic Toggle）

### 5.1 视觉规格

| 参数 | 值 |
|---|---|
| 轨道 | 52 × 32dp，胶囊形（圆角 16dp） |
| 滑块（thumb） | 24dp 圆形，带 1px 高光描边 |
| 关闭态 | `surfaceContainerHighest` 轨道 + `outline` 描边 |
| 开启态 | `primary(40)` 渐变轨道 + 白色滑块 + 内侧微光 |

### 5.2 动态层次（三态增强）

在 M3 Switch 基础上叠加三个动态细节：

1. **开关时滑块内图标渐变**：关 = 细线月亮，开 = 光点，图标随滑块位移淡入淡出
2. **涟漪扩张**：点击时从滑块位置扩散 1 圈 primary 10% 水波纹（`animateColorAsState`）
3. **轨道辉光**：开启时轨道外圈 8dp 范围有 primary 8% 的辉光晕染，关闭时消散

### 5.3 动效规格

| 动效 | 时长 | 曲线 |
|---|---|---|
| 滑块位移 | 220ms | `Spring(0.55, 400)` |
| 轨道颜色过渡 | 240ms | `FastOutSlowInEasing` |
| 辉光显隐 | 300ms | `LinearOutSlowInEasing` |
| 图标切换 | 160ms | `FastOutSlowInEasing` |

## 6. 播放器实用化重构

### 6.1 铁律：功能零损失

现有 `PlayerViewModel` 已提供的能力**全部保留**，重构只改外观与布局：

| 功能 | 保持 | 重构方向 |
|---|---|---|
| 播放 / 暂停 | ✅ | 主按钮 = 大号液态圆钮（64dp） |
| 进度 seek | ✅ | 胶囊滑杆 + 时间戳 + 缓冲条 |
| 倍速 1→1.25→1.5→2x | ✅ | 液态胶囊按钮，当前倍速大字居中 |
| 静音 | ✅ | 胶囊图标按钮，静音时红色角标 |
| 全屏 | ✅ | 右上胶囊图标，全屏后控制层自适应旋转 |
| 播放列表（全部历史） | ✅ | 底部"上滑查看更多"玻璃抽屉 |

### 6.2 布局（竖屏 / 横屏）

**竖屏**：

```
┌─────────────────────────────────┐
│  ← 返回   标题（玻璃胶囊条）      │  ← L2 浮层，自动隐藏
├─────────────────────────────────┤
│                                 │
│        ┌─────────────┐          │
│        │   视频画面    │          │  ← 16:9 居中，黑底
│        │   （ExoPlayer）│          │
│        └─────────────┘          │
│                                 │
├─────────────────────────────────┤
│  ⏪ -15s   ▶/⏸ 64dp   ⏩ +15s   │  ← L2 玻璃控制层
│  ────────●────── 缓冲  ──────   │  ← 胶囊滑杆
│  01:23 / 03:45                   │
│  [1.5x] [🔇] [📺]  [↑ 列表]     │  ← 液态胶囊操作排
└─────────────────────────────────┘
```

**横屏（全屏）**：控制层上下拆分——顶部返回/标题玻璃条，底部控制层；视频占满全屏，控制层自动 3 秒后淡出，轻触唤出。

### 6.3 易观看性设计（关键优化）

| 痛点（现状） | 解决 |
|---|---|
| 控制按钮小、难点中 | 全部触控目标 ≥ 44dp；主播放键 64dp |
| 进度条细、无缓冲反馈 | 滑杆 6dp 高 + 缓冲次级条 + 已播亮色胶囊头 |
| 倍速显示不明显 | 倍速按钮显示 `1.5x` 大字，循环切换时数字弹性缩放 |
| 控制层常驻遮挡画面 | 3 秒无操作自动淡出（`AnimatedVisibility` + 透明度），点按唤出 |
| 暗色场景看不清 | 控制层玻璃暗色参数（不透明度 62% + 高光描边） |
| 视频画面明暗不定 | 播放键置于画面内层（视频上方），用 `onSurface` 对比 |

### 6.4 迷你播放条（新增，不占功能）

返回列表后显示底部迷你条：缩略图 + 标题 + 播放/暂停 + 进度细线。点击展开播放器，滑动可关闭。作为 L2 浮层悬浮于底栏上方。

## 8. Compose 技术映射（落地要点）

| 需求 | API 方案 |
|---|---|
| 莫奈动态取色 | `dynamicLightColorScheme(context)` / `dynamicDarkColorScheme(context)`（API 31+），封装 `MonetColorScheme()`，低版本走 `fallbackColorScheme()` |
| 实时模糊 | `Modifier.blur()`（API 31+）或 `Modifier.graphicsLayer { renderEffect = BlurEffect(radius, radius) }`；低版本走 `GlassSurface` 模拟分支 |
| 玻璃组件封装 | 新建 `ui/components/GlassSurface.kt`（含 Tier 分级、高光描边、边缘光渐变） |
| 液态胶囊 tab | 完全自定义绘制：`Box` + `Canvas` + `AnimatedVisibility`，不用 M3 `NavigationBar` |
| 动态开关 | 基于 M3 `Switch` + `Modifier.then` 叠加辉光/涟漪/图标，或完全自绘 |
| 弹性动画 | `androidx.compose.animation.core.Spring` |
| 背景色域渐变 | `Brush.verticalGradient(primary.copy(alpha=0.12f), Transparent)` |
| 播放器控制层 | `AnimatedVisibility` + `alpha` 自动隐藏协程（`delay(3000)` + 手势唤醒） |

## 9. 无障碍（WCAG AA）

| 项目 | 规格 |
|---|---|
| 正文对比度 | ≥ 4.5:1（玻璃上文本用全不透明 onSurface） |
| 大文本对比度 | ≥ 3:1（标题、倍速数字） |
| 触控目标 | ≥ 44×44dp（播放键 64dp） |
| 状态辨识 | 颜色 + 形状双通道（不依赖纯色） |
| 动态取色安全 | 预设色与状态色固定对比度验证通过 |
| 减少动态效果 | 尊重 `Settings.Global.ANIMATOR_DURATION_SCALE == 0`，关闭弹性动画 |
| 键盘/读屏 | 液态 tab 保留 `semantics { role = Tab }`；开关保留 ToggleableState |
