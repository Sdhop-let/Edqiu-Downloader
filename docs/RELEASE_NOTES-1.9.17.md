# v1.9.17 更新内容

**主题：全库工程审计与修复（11 项 P1 + 约 45 项 P2/P3）+ 仅支持 Android 13+**　versionCode 66

2026-11-07 对全部源码做了一轮系统性排查（下载链路 / WebDAV 备份 / 订阅检测 / 界面与生命周期四路），发现的问题当日全量修复。本版没有新功能，是一次「把地基夯实」的稳定性版本。

## 支持范围变更：仅支持 Android 13+（定案）

- **minSdk 24 → 33**：此后只支持 Android 13 及以上设备。理由：隐私模式真高斯模糊、现代存储路径在全量设备上可用，低版本兼容代码成为纯负担；Android 12 及以下设备请停留在 v1.9.16（功能完整，只是不再收到更新）。

## 下载与画质

- **yt-dlp 卡死看门狗**：下载进程停滞 15 分钟自动强杀重试（原先是永久卡住）；补 socket 超时，网络假死不再挂起任务
- **画质选择规约化**：统一 `bestvideo+bestaudio/best`，确保 1080p+ 源不被降级
- **画质升级不再误删文件**：升级结果改三态判定（已升级 / 无增益 / 失败）并校验数据库行数，失败路径不会再把已有文件删掉
- **混合推文补拉图片**：视频+图片混合推文走 yt-dlp 下载视频后，自动补齐图片部分
- 磁盘满预检 + ENOSPC 错误翻译成人话；416 异常自动清零重下；孤儿 `.part` 启动时清理；下载并发槽引用计数防泄漏；下载页卡片终态及时裁剪

## WebDAV 备份可靠性

- **假成功终局复核**：网关收完大文件后响应超时的场景，改用三态探测（确认已落地 / 确认缺失 / 未知），限流误报不再被记成「失败重传」或「假成功」
- **绝不覆盖铁律加固**：MOVE 不受支持时不再发出注定失败的重命名请求，保住「不覆盖已有备份」底线
- 备份文件 tmp+rename 原子落地；PROPFIND 解析失败明确中止本轮；同轮重试次数封顶；手动同步进行中可正确再入
- **前台服务合规**：同步 / 下载 Worker 在 Android 14+ 正确挂 dataSync 前台（通知渠道惰性创建，失败自动降级）

## 订阅与检测

- **订阅表复合主键（作者, 平台）**：不同平台的同名作者不再互相顶替；数据库 v15 → v16，覆盖安装自动迁移
- 429 限流按轮熔断，不再无谓重试；Instagram shortcode 全量去重；rest_id 解码修复
- 订阅初始水位取「当前时刻 - 5 分钟」，新建订阅不漏当刻作品；新订阅首轮结果如实回报
- 元数据 / 封面抓取接通应用内代理；X / Bluesky 检测共享连接池

## 隐私与安全

- **第三方 API Key 改 SecretBox 加密存储**（旧明文自动迁移）；Cookie 文件仅 Instagram 通道按需写、用完即删
- 剪贴板 / 分享日志仅 debug 构建输出，release 构建零残留；清单热更响应做格式白名单校验
- debug 构建启用 StrictMode（开发期自检，不影响用户）

## 界面与性能

- **长列表卡顿改善**：媒体库统计与筛选链缓存、列表生命周期感知收集、收件箱计数缓存、过滤排序移出主线程
- 收件箱红点归属修正（红点挂在收件箱 Tab 上）
- 播放器：隐私模式「按住查看」加入位移意图判定，滚动不会误触穿帮；进程死亡后重进自动重建播放会话；翻页后不再违规自动起播
- 头像读取崩溃防护；我的页 ID 输入校验（仅字母 / 数字 / `_` / `.`）；备份中心纳入订阅配置，恢复不再丢订阅设置
- 死代码清理（`StatusChip` / `releaseIfIdle` 等）

## 兼容性

- 数据库 v15 → v16 覆盖安装自动迁移（真机已抽验迁移 / 红点 / 隐私模糊；**建议升级前在 设置 · 备份中心 做一次网盘备份**）
- 签名不变（v1.9.11 更换后的正式密钥），v1.9.11+ 直接覆盖安装，数据全保留
- **Android 13+（API 33）**，Android 12 及以下请停留在 v1.9.16 · 仅 arm64-v8a
