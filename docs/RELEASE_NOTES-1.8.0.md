# Edqiu v1.8.0

> 覆盖安装即可：与本项目历史版本同包名（com.ed.Edqiu）同签名，
> 收件箱数据、Cookie / 代理 / WebDAV 配置与订阅全部保留，无需卸载重装。

## 新增 · 玻璃外观参数组

外观设置新增「玻璃外观」卡组，把此前**硬编码**的四项外观参数开放为可调项，改动实时生效：

| 参数 | 范围 | 默认 | 作用 |
|---|---|---|---|
| 玻璃描边粗细 | 0 – 2.5 dp | 1.25 dp | 玻璃内描边线宽；0 = 不描边 |
| 玻璃亮边强度 | 0 – 1.6× | 1.00× | 等比缩放内描边高光与顶部光带；0 = 熄灭高光 |
| 玻璃描边颜色 | 取色器 | 跟随主题色 | 仅替换内描边的主题色层 |
| 玻璃压暗程度 | 0 – 100% | 0% | 压暗玻璃材质，深色模式下自动 ×1.5 |

- 四项同时作用于卡片面板与真折射浮层，各层级统一跟随。
- **升级零回归**：默认值即 v1.7.0 的既有行为，未主动调整则观感完全一致。
- 卡组底部提供**分组级「恢复默认」**——只回退本组四项，不动透明度 / 磨砂 / 折射 / 液态玻璃开关；
  参数全为默认值时按钮自动置灰。
- 描边颜色选定后行下方出现「改回跟随主题色」，无需重置整组即可回到主题色。
- 参数渲染改为规格表驱动：后续新增标量参数只需追加一行，设置页不会随参数增长而膨胀。

## 兼容性

- 新增首选项键均为独立键，缺失时取默认值，**不涉及既有偏好迁移**。
- 真折射（AGSL）仍需 Android 13+；低版本或关闭液态玻璃时，描边粗细 / 亮边强度 / 压暗程度
  在模拟玻璃面板上同样生效。
- 视频播放器控制层玻璃保持固定观感，刻意不跟随本组参数（需在动态彩色画面上保持低调稳定）。

## 设计取舍

本组参数参考了一份 iOS 26「液态玻璃」设计报告的参数组织方式，按本项目已有架构做了取舍：

- **采用**：正交命名（对象 × 属性）、分组卡片 + 组内恢复默认、规格表驱动的参数渲染。
- **未采用固定色板**：本项目配色是刻意收敛的「单一色源」方案（壁纸 Monet / 强调色派生）。
  描边颜色因此只作为**局部材质属性**开放，默认跟随主题色，不参与 ColorScheme 派生。
- **未采用「深色阴影浓度 ×2」**：玻璃投影已在 2026-09-21 整体移除（透明后投影会从背后透出成色块），
  该规则无对象可加，其意图（深色下补偿材质信号）改由**压暗程度 ×1.5** 承接。
- **未采用暖白文字 / 17sp 正文 / MiSans 可变字体**：前者与 Monet 取色冲突且影响对比度保证；
  后两者与信息密集型界面尺度和「仅 arm64、包体约 80MB」的控制目标冲突。

## 验证

- `assembleDebug`（默认 arm64 与 `-PemulatorAbi=x86_64`）与 `assembleRelease` 均构建通过。
- 模拟器实测（Android 15 / API 35）：四项参数拖动即时生效；「恢复默认（本组）」一键回退并置灰。
