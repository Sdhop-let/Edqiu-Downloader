# Edqiu v1.8.0

> 覆盖安装说明：本版本与历史版本同包名（com.ed.Edqiu）同签名，直接覆盖安装即可，
> 收件箱数据、Cookie/代理/WebDAV 配置与订阅全部保留，无需卸载重装。

## 新增

- **「玻璃外观」参数组**：外观设置新增独立卡组，在原有「透明度 / 磨砂 / 折射」三参数之上，
  补齐四项此前硬编码的外观参数——现已全部可调、实时生效：

  | 参数 | 范围 | 默认 | 作用 |
  |---|---|---|---|
  | 玻璃描边粗细 | 0 – 2.5 dp | 1.25 dp | 玻璃内描边的线宽；0 = 不描边（纯色磨砂面板） |
  | 玻璃亮边强度 | 0 – 1.6× | 1.00× | 等比缩放内描边高光与顶部光带；0 = 熄灭高光 |
  | 玻璃描边颜色 | 取色器 | 跟随主题色 | 仅替换内描边的主题色层，默认不改变配色 |
  | 玻璃压暗程度 | 0 – 100% | 0% | 在玻璃材质层压暗，深色模式下自动 ×1.5 补偿 |

  四项参数同时作用于卡片面板（`GlassSurface`）与真折射浮层（`GlassOverlaySurface`），
  各层级统一跟随。

- **分组级「恢复默认」**：「玻璃外观」卡组底部提供独立的恢复默认按钮——只回退本组四项，
  不触碰透明度 / 磨砂 / 折射 / 液态玻璃开关等其它设置；参数全为默认值时按钮自动置灰。

- **描边颜色「改回跟随主题色」**：选用自定义描边色后，行下方出现一键改回入口，
  避免只能靠重置整组才能回到主题色。

- **深色模式压暗补偿**：深色背景下同等压暗更难被感知，故「压暗程度」在深色模式
  自动 ×1.5 渲染（浅色模式按设置值原样）。默认值 0 时两种模式均不产生压暗，
  既有用户观感不受影响。

## 设计说明：参数体系的定制化适配

本次参数扩展参考了一份 iOS 26「液态玻璃」设计逆向分析报告的参数组织方式，
并按 Edqiu 现有架构做了取舍，**未**照搬的部分及原因记录如下，便于后续追溯：

- **采用**：正交命名法（「对象 × 属性」——对象=玻璃，属性=粗细/强度/程度/颜色）、
  分组卡片 + 组头说明 + 分组级恢复默认、数据驱动的参数渲染（规格表 → 滑块，
  新增标量参数只需往表里加一行，设置页不随参数增长线性膨胀）。
- **未采用 · 固定 iOS 色板**：Edqiu 的配色是刻意收敛的「单一色源」方案（壁纸 Monet /
  强调色派生，见 `Theme.kt` 注释）。引入固定主色板会与壁纸取色互相打架，故仅让
  描边颜色作为**局部材质属性**开放，且默认跟随主题色，不参与 ColorScheme 派生。
- **未采用 · 深色阴影浓度 ×2**：Edqiu 在 2026-09-21 已整体移除玻璃投影
  （投影在玻璃透明后会从背后透出成长方形色块）。原报告的「阴影加倍」规则无对象可加，
  其设计意图（深色下补偿材质信号）改由**压暗程度 ×1.5** 承接。
- **未采用 · 暖白文字**：文字色由 Material `colorScheme.onSurface` 提供，
  硬编码暖白会与 Monet 取色冲突且破坏对比度保证，故不动。
- **未采用 · 17sp 正文基准与 MiSans 可变字体**：Edqiu 是信息密集型列表界面，
  正文基准为 13–17sp 的 Material 尺度；MiSans VF 字体文件约 20MB，与「仅 arm64
  单架构、APK 约 80MB」的包体控制目标冲突。

## 兼容性

- **升级零回归**：四项新参数的默认值均为此前的硬编码行为（1.25 dp / 1.00× /
  跟随主题色 / 0%），未主动调整的用户升级后观感与 v1.7.0 完全一致。
- 新增首选项键（`glass_edge_width` / `glass_edge_light_strength` /
  `glass_edge_color_argb` / `glass_dim_amount`）均为独立键，缺失时取默认值，
  不涉及既有偏好迁移。
- 真折射路径（AGSL 折射）仍需 Android 13+；低版本与非液态玻璃模式下，
  描边粗细 / 亮边强度 / 压暗程度在模拟玻璃面板上同样生效。
- 视频播放器控制层玻璃（`MediaGlassSurface` + `FallbackDarkGlassSurface`）为固定观感，
  刻意不跟随本次新参数——该处需要在动态彩色画面上保持低调稳定。

## 涉及改动

- `ui/theme/ThemeEffects.kt` — 新增四个 CompositionLocal + 深色压暗补偿计算
- `data/preferences/SettingsRepository.kt` — 四个新键 / 读写方法 / 分组重置 / 是否默认流
- `ui/components/GlassSurface.kt` — 内描边消费粗细 / 亮边强度 / 描边色，新增压暗层
- `ui/components/LiquidGlass.kt` — 真折射路径消费压暗与亮边强度
- `ui/navigation/AppNav.kt` — 四项参数的注入与哨兵值映射（0 = 跟随主题色 → Unspecified）
- `ui/settings/SettingsScreen.kt` — 「玻璃外观」卡组、复用取色器（标题可配置）、分组恢复默认

## 验证

- 编译：`assembleDebug`（默认 arm64 构型与 `-PemulatorAbi=x86_64`）均通过。
- 模拟器实测（Android 15 / API 35，x86_64）：四项参数拖动即时生效——
  描边粗细拉到 2.45 dp 卡片轮廓明显加粗；压暗程度 58% 玻璃明显变暗；
  描边色选珊瑚橙后卡片边缘转为暖色；「恢复默认（本组）」一键回到
  1.25 dp / 1.00× / 0% / 跟随主题色，按钮随即置灰。
