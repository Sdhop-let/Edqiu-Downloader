# v1.9.4 更新内容

**主题：液态玻璃光学升级（光源 · 折射 · 色散）+ 强调色定版 + 统计块数据可视化重设计**　versionCode 53

## 液态玻璃 · 光学升级（对齐 Apple 液态玻璃）

- **光学三参数体系**：新增「光源角度 / 光源亮度 / 色散强度」，与 Apple 液态玻璃（iOS 26）及设计工具官方教程的参数体系一一对应——玻璃不再靠"磨砂贴膜感"，而是靠方向性高光与边缘色差撑起真玻璃质感
- **方向性光源**：高光带从"正顶部横带"改为沿光源方向渐变（默认 **-45° = 左上方**，Apple 惯例）——"贴膜感"的来源就是顶部横带，方向性高光才是"真玻璃在光下"
- **色散副描边**：玻璃边缘新增极微妙的暖/冷双副描边（模拟折射率随波长变化的彩虹色差），这是玻璃"贵感"的最大来源；默认半强度，可在设置中调至关闭
- **清透化**：整体磨砂雾感减半，玻璃主靠折射不靠磨砂——更接近 iOS 26 的清透观感
- **背景色场韵律化**：背景出现明暗起伏的色彩光斑（左上冷调亮团 / 右中深团 / 左下暖斑），玻璃有了可折射的"物"——纯均匀背景上任何玻璃参数都是空谈；顺带修复光斑硬编码像素坐标在不同分辨率下的错位
- **真折射深度增强**：底部导航栏与胶囊反馈的边缘折射带加宽（14 → 18dp），玻璃厚度感更实

## 强调色定版（设置页精简）

- **全局固定 iOS 绿（#34C759）**：强调色不再可配置——「颜色」设置卡组与取色器整体移除。该绿色是长期实机验证的观感：绿底白字对比达标、玻璃描边透绿、与青色构成协调背景色场
- **玻璃描边颜色设置移除**：描边恒随主题色（单一色源不可覆盖），相关取色器与存储一并清理
- 设置页**净删约 300 行**死代码，外观分区更干净

## 玻璃设置 · 光学三项可调

- 「玻璃外观」新增三个实时生效的滑块：**光源角度**（-180° ~ 180°，默认 -45°）/ **光源亮度**（默认 80%）/ **色散强度**（默认 50%）
- 「恢复默认（本组）」与默认状态判定已覆盖三项

## 统计块 · 数据可视化重设计

- **收件箱统计卡**：三段数字各带状态色圆点（待处理 = 橙 / 已完成 = 绿 / 失败 = 红，与状态标签同源）；有待处理或失败时该段数字自动变语义色浮出，平静态保持中性；数字改等宽排版防跳动；**卡底新增完成度条**——队列消化进度（已完成 / 总数）一眼可读
- **媒体库统计卡**：三张筛选卡各带类型小图标；**每卡底部新增占比条**，实时呈现该类型（视频 / 图片）在全部作品中的份额——筛选器与数据可视化合一
- 分隔线改两端渐隐，与玻璃材质语言统一

## 订阅与收件箱行为修正

- **订阅作品不再进入收件箱**：订阅线作品只进「作品订阅」页，收件箱回归"你手动捕获的链接"单一语义；收件箱计数同步排除订阅线
- **下载前媒体库去重**：订阅作品下载前先比对媒体库，已在库中的直接跳过并如实提示（不占下载队列）；失败重试不受影响，多图缺漏仍可补下
- **进软件轻提示**：离开期间订阅检测到的新作品数量，回前台时底部玻璃胶囊一句话告知（首次启动不打扰）
- 批量保存反馈语义修正：全部重复 = 中性提示（不是失败）

## 界面细节修正

- 底部 Tab 栏上移：手势导航模式下不再贴死屏幕底边（新增 24dp 安全间距）
- Tab 栏上方新增 52dp 渐进模糊带：列表滚入 Tab 栏区域的过渡更自然（Android 13+ AGSL 实现，低版本自动回退渐变）
- 媒体库搜索 / 刷新圆钮图标居中修复；下载中心 / 回收站返回钮居中修复
- 「我的」页头部与统计卡改版（数字 / 占用 / 收件箱计数一屏总览 + 关于本机版本直读）
- 移除一批历史遗留死代码（旧首页 / 旧视频信息卡 / 内嵌反馈条等），安装包更干净

## 兼容性

- 数据库版本不变（主库 v15 / 订阅库 v11），升级无迁移
- 强调色历史存储值自然失效（固定绿取代），其余设置全部保留
- 光学三项在 Android 13+ 上效果最完整；低版本自动回退渐变模拟
