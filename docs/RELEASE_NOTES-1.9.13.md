# v1.9.13 更新内容

**主题：壁纸舞台可读性三连修（白线 / 壁纸对齐 / 灰字对比度与字号）**　versionCode 62

## 修复

- **列表边缘白色分界线（收件箱顶部 / 媒体库顶部 / 收件箱底部白区）**：边缘渐隐缓冲带早期按「页面背景色」画渐变（浅色主题 = 90% 不透明白），壁纸舞台时代它盖在壁纸照片上就是一条刺眼白线。改为阴影式暗色渐隐——壁纸上读作「内容沉入阴影」，深浅主题皆自然
- **壁纸与桌面错位**：壁纸此前按居中裁切，与桌面壁纸的顶部锚定方式不一致（视觉上主体位置对不上桌面所见）。改为顶部对齐，与桌面观感一致
- **灰字可观度**：全局次级文字色加深（浅色 #8A8A8E→#5C5C61、深色 #9E9EA6→#B0B0B8）——壁纸照片上的灰色小字不再糊掉
- **小字号提升**：我的页菜单副标题 11→12sp（行高 16）、10.5→11.5sp 两处；收件箱统计卡指标标签 11→12sp；统计卡第四槽行高 46→54dp——修复「全部下载」标签被卡片下缘裁掉（文字丢失）
- 收件箱统计卡总高度相应 +8dp，折叠行为不变

## 兼容性

- 数据库版本不变（v15/v11），覆盖安装数据全保留；签名与 v1.9.11+ 相同
- Android 7.0+（API 24）· 仅 arm64-v8a
