## v1.9.0 · 2026-10-10

**主题：固定 iOS 式配色 + 大标题折叠体系（全量 UI 重构第一批）**　`versionCode 49`

### 配色体系重构（Monet 动态取色彻底移除）

- 壁纸取色 / 系统 Monet / materialkolor 派生引擎全部移除（含内嵌 materialkolor 源码 42 文件），
  壁纸变化不再影响任何界面颜色。
- 新配色 = **固定 iOS 式中性面**（浅色清透白 #FFFFFF/#F2F2F7 族、深色纯黑 #000000 + 石墨 #1C1C1E 族）
  + **单一强调色 tint**（默认 iOS 蓝 #007AFF），强调色只作用于按钮、开关、选中态与玻璃染色，
  不改变背景与文字层次。
- 强调色派生改为固定映射规则：深色模式 tint 自动提亮 10%，容器色 lerp 混色，onPrimary 按亮度取黑白——
  预设与自定义 HSV 色一视同仁，效果可预测。
- 强调色预设换 iOS 系统调色板（蓝/青绿/薄荷/靛紫/紫/粉/橙/琥珀/黄/绿/莓红/石墨），自定义取色保留。
- 状态语义色统一为 iOS 系统色（橙=未下载、绿=已下载、红=失败、灰=已删除），不随取色与强调色变化。
- 修复：设置页标题硬编码近黑 Ink 在深色模式下不可读的遗留 bug（→ onBackground 自适应）。
- 开屏改 iOS 惯例：中性背景 + 强调色品牌字，替代旧品牌蓝底。

### 大标题↔紧凑导航折叠体系

- 新增统一折叠组件（纯滚动状态驱动、180px 行程、可中断可回弹），接入收件箱 / 下载中心 /
  回收站 / 网盘备份四页：列表滚动时大标题平滑收缩为紧凑导航标题，副标题淡出。
- 列表内大标题页新增滚动后淡入的紧凑导航条（iOS「large title scrolls away」行为），
  下载中心/回收站补齐常驻返回钮。

### 回收站玻璃化

- 全工程最后一处 M3 原生形态（TopAppBar / BottomAppBar / 默认 Card）退场：
  列表项改 L1 玻璃卡、批量操作条改 L2 玻璃条，与收件箱同构。

### 动画统一

- 全局按压反馈增强：所有 `pressableNoRipple` 元素（设置行/菜单行/chip/卡片等 11 处）
  增加按压缩放 1.0→0.97（低刚度 spring 无机械弹跳），系统「减少动画」开启时自动降级为纯触感。

### 播放器控制层强化（第二批）

- 播放/暂停图标 Crossfade 平滑转换（替代瞬间切换，140ms）。
- 进度条拖动视觉增强：按下/拖动时 thumb 放大 3×、轨道增粗 2.4×，松手平滑回落；
  拖动期只更新本地进度、松手才 seek 的既有逻辑保留。
- 顶部玻璃条与动作面板的进出动画统一对齐主控制层规格（220/160ms）。

### 全页面收敛（第二批）

- 新增统一分段胶囊 `PillChip`（iOS 分段控制语义），替换全部 M3 FilterChip：
  备份范围、媒体类型筛选、画质选择、自动备份频率、攒批条数共 7 处。
- 新增统一 iOS 滑杆 `EdqiuSlider`（4dp 圆角轨道 + 白色带影 thumb + 拖动增强），
  替换设置页全部参数滑杆（透明度/磨砂/折射/玻璃外观三项/界面缩放）；
  取色器 HSV 滑杆保留透明轨道专属设计。
- 全部进度条统一 6dp 圆角胶囊（下载中心/收件箱进度/网盘备份/媒体备份）。
- 媒体备份页：标题接入大标题折叠、上传中状态改 primary 语义色。
- 空态图标底由旧主题硬编码 mint/blue 渐变改主题容器色；
  网盘状态点颜色统一 iOS 状态语义色。

### 动画令牌表与细节走查（第三批）

- 新增全局动画令牌 `ui/anim/Motion.kt`（语义化时长分层 Micro/Control/Panel/Screen/
  播放器变形专档 + 缓动曲线 + 三档弹簧），按压反馈、滑杆、播放器控制层、图片栏、
  折叠导航条五个统一组件的动画参数全部收口取值，杜绝动画参数继续发散。
- 详情页走查：无头像兜底由旧品牌天蓝改主题容器色；顶部圆钮底色对齐全工程统一形态；
  文案折叠动画接入令牌表。
- 更新对话框下载进度条统一 6dp 圆角胶囊（全工程最后一处方头进度条）。

### 兼容性

- 玻璃三滑块（透明度/磨砂/折射）、玻璃外观四项（描边/亮边/描边色/压暗）、液态玻璃开关、
  界面缩放、高刷新率、触感档位等全部既有设置保留不变。
- 旧数据无缝升级：取色相关配置键移除，强调色沿用原存储值（默认值变更只影响新安装）。

## v1.8.0 · 2026-10-09

**主题：玻璃外观参数化**　`versionCode 48`　[Release 页](../../../releases/tag/v1.8.0)

- 新增「玻璃外观」参数组，把此前硬编码的玻璃外观补齐为可调项：
  描边粗细（0–2.5 dp）、亮边强度（0–1.6×）、描边颜色、压暗程度（0–100%）。
- 四项默认值均等于 v1.7.0 的既有行为，升级后观感零回归。
- 分组级「恢复默认」（只回退本组）；描边颜色默认跟随主题色，不参与配色派生。
- 压暗程度在深色模式下自动 ×1.5 补偿。
- 参数渲染改为规格表驱动，后续新增标量参数只需追加一行。
