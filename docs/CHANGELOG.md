## v1.9.7 · 2026-10-24

**媒体库重做 · 渲染冻结根治**（versionCode 56）

- **媒体库排序改为下载时间（默认）**：刚下完的在最上（旧发布时间排序让今天下载的老作品沉底）；「按下载时间 ⇄ 按发布时间」胶囊切换并持久化；下载日分组（今天/昨天/日期）

- 性能：媒体库网格滚动 jank 1.54%（历史最佳）

**主题：液态玻璃光学升级（光源 · 折射 · 色散）+ 强调色定版 + 统计块数据可视化重设计**　`versionCode 53`

### 液态玻璃 · 光学升级

- 光学三参数体系（光源角度 / 光源亮度 / 色散强度），与 Apple 液态玻璃参数一一对应。
- 方向性光源：高光带从正顶部横带改为沿光源方向渐变（默认 -45° = 左上，Apple 惯例），告别"贴膜感"。
- 色散副描边：玻璃边缘极微妙的暖/冷双描边（模拟彩虹色差），玻璃"贵感"的核心；默认半强度。
- 整体磨砂雾感减半——玻璃主靠折射不靠磨砂，更清透。
- 背景色场韵律化：明暗起伏的色彩光斑给玻璃可折射的"物"；顺带修复光斑硬编码像素的分辨率错位。
- 真折射深度增强：底栏与胶囊边缘折射带 14 → 18dp。

### 强调色定版（设置页精简）

- 全局固定 iOS 绿 #34C759，「颜色」设置卡组与取色器整体移除；玻璃描边颜色设置一并移除（描边恒随主题色）。
- 设置页净删约 300 行死代码。

### 玻璃设置 · 光学三项可调

- 「玻璃外观」新增实时生效的滑块：光源角度（-180°~180°，默认 -45°）/ 光源亮度（默认 80%）/ 色散强度（默认 50%）；恢复默认已覆盖三项。

### 统计块 · 数据可视化重设计

- 收件箱：状态色圆点（橙/绿/红与状态标签同源）+ 异常数字自动浮出 + 等宽数字 + 卡底完成度条（已完成/总数）。
- 媒体库：筛选卡带类型图标 + 每卡底部占比条（该类型占全部作品份额）——筛选器与数据可视化合一。

### 订阅与收件箱行为修正

- 订阅作品不再进入收件箱（只进「作品订阅」页），收件箱计数同步排除。
- 下载前媒体库去重：已在库中的订阅作品直接跳过并如实提示；失败重试与多图补下不受影响。
- 进软件轻提示：离开期间订阅更新数量，回前台胶囊一句话告知。
- 批量保存全部重复 = 中性提示（不是失败）。

### 界面细节修正

- 底部 Tab 栏手势模式下不贴死屏底（24dp 安全间距）；Tab 栏上方 52dp 渐进模糊带（Android 13+ AGSL，低版本回退渐变）。

## v1.9.3 · 2026-10-17

**主题：作者订阅 X 检测通道重建 + 订阅改选择性下载 + 预下载退役 + 弹窗体系升级**　`versionCode 52`

### 作者订阅 · X 检测通道重建

- 旧通道废弃：yt-dlp 不支持 X 用户主页时间线（`Unsupported URL`），v1.9.2 的订阅检测自上线起即不可用，且失败被静默吞成「暂无新作品」。
- 重建为 X GraphQL 直连：guest token 主通道（免登录）→ 登录 Cookie 兜底；新鲜度门闩（最新推文 > 30 天视为降级）自动升级 Cookie 通道。
- queryId 远程静默轮换：陈旧签名触发仓库 `x_api_manifest.json` 热更新并重试；代理开启时每 7 天静默保鲜，接口变更不需要发版。
- 检测失败九类分类透出（未走代理 / 代理超时 / Cookie 失效 / 接口轮换失败…），订阅行 ⚠ 常驻显示，每条带操作指引。

### 订阅改选择性下载

- 检测到新作品只收录进收件箱与「订阅消息」，**不再自动下载**——点按后再下载（与手动下载同语义）。
- 订阅起始日期自定义：只检测该日期之后发布的新帖。
- 订阅消息区重做三段式：新作品数量卡 → 检测状态卡（逐作者上次检测 / 失败原因 / 最近事件）→ 帖子列表（收件箱同款卡片，可直接点按下载）。

### 预下载功能退役

- 预下载（攒批自动下载）整体移除，含设置页开关与待处理提示弹窗；下载完成后的网盘自动联动保留。
- 收件箱「下载」按钮批量下载全部待处理的能力不变。

### 下载与弹窗体系升级

- 引擎熔断按发起方隔离：后台路径下载失败不再计入全局熔断器，手动下载永不被后台误伤。
- 操作结果升级中央弹窗（批量下载汇总 / 下载失败含引擎链原因 / 无效链接）；瞬时状态仍走底部玻璃胶囊。
- 胶囊提醒抬升至底部 Tab 栏上方，不再遮挡。
- 弹窗加宽至 86% 屏宽（上限 560dp）、退场动画并行单段 180ms、单按钮居中；失败文案区分「近期失败跳过」与「全局熔断」。

### 兼容性

- 主库 v12 → v15（订阅失败原因 / 订阅消息表 / 订阅起始日期）；订阅库 v10 → v11（作品来源标记）；全部自动迁移，数据无损。

## v1.9.2 · 2026-10-15

**主题：WebDAV 同步重构 + 真正作品订阅 + 设置页信息架构重做**　`versionCode 51`

### WebDAV 同步重构

- 网盘备份中心整体移除：WebDAV 同步页即唯一配置与同步入口，幂等改由远端尺寸对账保证。
- 每网盘独立账号配置（地址 / 账号 / 密码加密 / 远程目录 / 验证结论独立存储，切换互不覆盖）；
  仅「测试连接」成功才落盘，失败不保存；旧配置自动迁移。
- 同步情况详情页重做：「同步 | 已同步」双分页 + 逐文件三态对账 + 正在同步高亮置顶 +
  逐个暂停 / 恢复 / 置顶优先；页面不透明全屏化。
- 传输可靠性：上传对账改单次 PROPFIND（修复「无法确认远程文件状态」）、瞬态退避重试、
  对账双名兼容（存量文件不再误判未同步）、断点续传每轮重试重新探测断点、连接池保活 90s。

### 真正作品订阅

- 独立二级菜单页：订阅列表（平台徽标 / 启停 / 逐条检测）+ 手动添加 + 立即检测全部。
- 双端一键订阅：作者中心卡片按钮；播放器作者行常驻铃铛（与 ⋮ 菜单状态联动）。
- 多平台检测：X（yt-dlp）/ Bluesky（公共 AppView API，免登录）/ Instagram（yt-dlp，实验性）。
- 闭环：25 分钟轮询（防风控节流），新作品自动入收件箱并按下载链下载。

### 设置页信息架构重做

- 「我的」页改六张领域卡（卡即分组，全部入口重命名）：作品库 / 订阅与自动化 / 网络与同步 /
  外观与播放 / 存储与备份 / 通用；作品订阅归入「订阅与自动化」。
- 玻璃卡下沉卡级（每卡独立 L1 玻璃）、卡间分隔线移除、间距统一 12dp。

### 兼容性

- 检测库 v12（订阅 platform 列）/ 主库 v10（移除备份账本表），存量数据自动迁移；
  网盘备份中心配置随功能失效；旧版本可直接覆盖安装。

**主题：设计系统组件化收尾——输入场与多选控件全面统一**　`versionCode 50`

### 统一 iOS 输入场（27 处全量迁移）

- 新增统一输入场组件 `EdqiuTextField`：iOS 填充式风格——浅灰圆角填充面、常态无边框，
  聚焦时填充提亮一档 + 强调色细描边浮现，光标走强调色；标签为场外上方独立小字
  （iOS 分组表单语言），替代 Material 浮动标签。
- 全应用 27 处输入框统一换装：设置页 17 处（下载路径 / 代理 / Cookie / 第三方 API /
  WebDAV / 攒批条数等）、首次引导 4 处（Cookie 与代理配置）、云备份 5 处
  （WebDAV 表单与网盘授权）、收件箱粘贴捕获框与媒体库搜索框；
  收件箱顶部「粘贴链接」输入条（UrlInputBar）同步统一。
- Material 描边框输入样式（OutlinedTextField）全工程退场。

### 多选勾选圆圈（iOS 风）

- 新增统一组件 `CheckCircle`：收件箱批量管理勾选框由 Material Checkbox 替换为
  iOS 风勾选圆圈——未选中为中性描边空心圆，选中为强调色实心圆 + 白勾 spring 弹入。
- 无障碍语义保留（`Role.Checkbox`，读屏行为不变）；系统「减少动画」开启时跳变呈现。

### 仓库清理

- 移除三个零调用死组件（`SettingGroup` / `HistoryVideoItem` / `DownloadProgressItem`）
  与遗留死导入；界面行为零变化。
- 新增设计验收清单 `docs/design/AUDIT-CHECKLIST.md`：设计令牌速查（配色 / 圆角 / 动画 /
  玻璃层级）+ 视觉 / 动画 / 工程 / 真机四节发布前走查表。

### 兼容性

- 全部既有设置与数据不变；多选、粘贴捕获、WebDAV 配置等业务逻辑零改动；
  旧版本直接覆盖安装。

## v1.9.0 · 2026-10-10

**主题：固定 iOS 式配色 + 大标题折叠体系（全量 UI 重构第一批）**　`versionCode 49`

### 配色体系重构（Monet 动态取色彻底移除）

- 壁纸取色 / 系统 Monet / materialkolor 派生引擎全部移除（含内嵌 materialkolor 源码 42 文件），
  壁纸变化不再影响任何界面颜色。
- 新配色 = **固定 iOS 式中性面**（浅色清透白 #FFFFFF/#F2F2F7 族、深色纯黑 #000000 + 石墨 #1C1C1E 族）
  + **单一强调色 tint**（默认 iOS 蓝 #007AFF），强调色只作用于按钮、开关、选中态与玻璃染色，
  不改变背景与文字层次。
- 强调色派生改为固定映射规则：深色模式 tint 自动提亮 10%，容器色 lerp 混色，onPrimary 按亮度取黑白——
  预设与自定义 HSV 色一视同仁，效果可预测。
- 强调色预设换 iOS 系统调色板（蓝/青绿/薄荷/靛紫/紫/粉/橙/琥珀/黄/绿/莓红/石墨），自定义取色保留。
- 状态语义色统一为 iOS 系统色（橙=未下载、绿=已下载、红=失败、灰=已删除），不随取色与强调色变化。
- 修复：设置页标题硬编码近黑 Ink 在深色模式下不可读的遗留 bug（→ onBackground 自适应）。
- 开屏改 iOS 惯例：中性背景 + 强调色品牌字，替代旧品牌蓝底。

### 大标题↔紧凑导航折叠体系

- 新增统一折叠组件（纯滚动状态驱动、180px 行程、可中断可回弹），接入收件箱 / 下载中心 /
  回收站 / 网盘备份四页：列表滚动时大标题平滑收缩为紧凑导航标题，副标题淡出。
- 列表内大标题页新增滚动后淡入的紧凑导航条（iOS「large title scrolls away」行为），
  下载中心/回收站补齐常驻返回钮。

### 回收站玻璃化

- 全工程最后一处 M3 原生形态（TopAppBar / BottomAppBar / 默认 Card）退场：
  列表项改 L1 玻璃卡、批量操作条改 L2 玻璃条，与收件箱同构。

### 动画统一

- 全局按压反馈增强：所有 `pressableNoRipple` 元素（设置行/菜单行/chip/卡片等 11 处）
  增加按压缩放 1.0→0.97（低刚度 spring 无机械弹跳），系统「减少动画」开启时自动降级为纯触感。

### 播放器控制层强化（第二批）

- 播放/暂停图标 Crossfade 平滑转换（替代瞬间切换，140ms）。
- 进度条拖动视觉增强：按下/拖动时 thumb 放大 3×、轨道增粗 2.4×，松手平滑回落；
  拖动期只更新本地进度、松手才 seek 的既有逻辑保留。
- 顶部玻璃条与动作面板的进出动画统一对齐主控制层规格（220/160ms）。

### 全页面收敛（第二批）

- 新增统一分段胶囊 `PillChip`（iOS 分段控制语义），替换全部 M3 FilterChip：
  备份范围、媒体类型筛选、画质选择、自动备份频率、攒批条数共 7 处。
- 新增统一 iOS 滑杆 `EdqiuSlider`（4dp 圆角轨道 + 白色带影 thumb + 拖动增强），
  替换设置页全部参数滑杆（透明度/磨砂/折射/玻璃外观三项/界面缩放）；
  取色器 HSV 滑杆保留透明轨道专属设计。
- 全部进度条统一 6dp 圆角胶囊（下载中心/收件箱进度/网盘备份/媒体备份）。
- 媒体备份页：标题接入大标题折叠、上传中状态改 primary 语义色。
- 空态图标底由旧主题硬编码 mint/blue 渐变改主题容器色；
  网盘状态点颜色统一 iOS 状态语义色。

### 动画令牌表与细节走查（第三批）

- 新增全局动画令牌 `ui/anim/Motion.kt`（语义化时长分层 Micro/Control/Panel/Screen/
  播放器变形专档 + 缓动曲线 + 三档弹簧），按压反馈、滑杆、播放器控制层、图片栏、
  折叠导航条五个统一组件的动画参数全部收口取值，杜绝动画参数继续发散。
- 详情页走查：无头像兜底由旧品牌天蓝改主题容器色；顶部圆钮底色对齐全工程统一形态；
  文案折叠动画接入令牌表。
- 更新对话框下载进度条统一 6dp 圆角胶囊（全工程最后一处方头进度条）。

### 兼容性

- 玻璃三滑块（透明度/磨砂/折射）、玻璃外观四项（描边/亮边/描边色/压暗）、液态玻璃开关、
  界面缩放、高刷新率、触感档位等全部既有设置保留不变。
- 旧数据无缝升级：取色相关配置键移除，强调色沿用原存储值（默认值变更只影响新安装）。
