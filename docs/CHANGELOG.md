## v1.8.0 · 2026-10-09

**主题：玻璃外观参数化**　`versionCode 48`　[Release 页](../../../releases/tag/v1.8.0)

- 新增「玻璃外观」参数组，把此前硬编码的玻璃外观补齐为可调项：
  描边粗细（0–2.5 dp）、亮边强度（0–1.6×）、描边颜色、压暗程度（0–100%）。
- 四项默认值均等于 v1.7.0 的既有行为，升级后观感零回归。
- 分组级「恢复默认」（只回退本组）；描边颜色默认跟随主题色，不参与配色派生。
- 压暗程度在深色模式下自动 ×1.5 补偿。
- 参数渲染改为规格表驱动，后续新增标量参数只需追加一行。

## v1.7.0 · 2026-10-07

**主题：备份与更新体验**　`versionCode 47`　[Release 页](../../../releases/tag/v1.7.0)

- 网盘备份中心整合进「WebDAV 同步」页，多网盘直连备份一处管理。
- 更新弹窗改版：展示更新内容 + 国内镜像 / GitHub 官方双下载源（镜像下载后仍做签名自校验）。
- 开屏显式「跳过」入口；首次引导错峰入场动画与跟手指示器；渲染冻结自愈监视器。
- 修复：WebDAV 浮层返回链路穿透、播放器媒体框比例跟手形变、连续滑动后退场定位。
- 发版：Release CI 支持正式签名（Secrets 配置齐备时构建 `assembleRelease`，可覆盖升级）。
