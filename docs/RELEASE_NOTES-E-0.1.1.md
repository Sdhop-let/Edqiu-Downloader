# E-0.1.1 更新内容

**主题：下载进度回弹根治 + 下载前视频源选型 + 隐私长按 3 秒状态机修复 + 构建链升级**　versionCode 101

2026-11-20 发布。本版集中治理两个用户实测反馈的下载 / 隐私问题，并升级全套构建工具链。

## 下载修复

- **进度回弹根治**：修复「下载到 99% 回弹到 0% 或其他值重新下载」——yt-dlp 音视频分段下载的进度按「流 + 格式身份」峰值聚合、固定阶段总进度，同格式重试不再被误认成新流，显示进度单调不减。
- **画质判断提前到下载前**：废除「下载后码率实测不达标 → 删除文件再重下一次 mp4」的旧闸门（真实重传的元凶）。改为下载前用格式表实证选源（短边 / 像素 / 帧率 / 码率择优），选定后一次传输到位；有效成品不再因名义码率比对被拒收删除。
- **有声源永不静音**：选源守门保证 video-only 候选必须配套音频流，有声推文绝不回退为纯视频。
- **多媒体续传只补缺项**：新增私有任务清单，部分媒体已落盘时重试仅补缺项，禁止跨引擎整条推文重下；补缺任务不再打熔断、不影响引擎亲和。
- **收件箱进度聚合重写**：排队媒体计入总进度分母、按当前引擎分组展示，终态交回数据库状态——多条媒体切换时进度平滑过半而非归零，也不再有「永久卡 99%」。
- **换源提示可见**：高画质源失败切换直连源时，下载中心显示阶段提示（与最终错误分离，不再误读为失败）。
- **cookie 并发互踩根治**：cookie 文件改专属临时文件所有权，并发下载不再互相覆盖。

## 隐私模式

- **长按 3 秒显示修复**：重写为持续按压状态机——手指按住满 3 秒才临时显示隐藏内容，松手、滑动、手势离开立即恢复；手势被系统取消不再误触发显示或误触点击。收件箱卡片与详情页同规则。

## 构建与工程

- **构建链升级**：Gradle 9.7.1 → 9.9.0 / AGP 9.3.2 → 9.5.1 / Kotlin 2.4.10 → 2.4.21；core-ktx 1.19.1、navigation 2.10.2、WorkManager 2.12.0。
- 新增 48 项单元测试全绿（视频源策略 / 分段进度聚合 / 收件箱聚合三大核心逻辑），全量编译零错误。
