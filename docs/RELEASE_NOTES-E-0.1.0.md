# E-0.1.0 更新内容

**主题：版本体系重置（1.x → E-0.x）+ 下载链路断网/画质治理 + 隐私模式文字隐藏 + WebDAV 修复 + 界面精简**　versionCode 100

2026-11-12 起，Edqiu 进入新的版本纪元：版本号从 v1.9.17 重置为 **E-0.1.0**（E 取自 Edqiu，0.1.0 为语义化版本，此后每个小版本 +1 迭代，如 E-0.1.1）。功能上延续 v1.9.17，并一次性合入了 2026-11-11 以来累积的一批下载链路修复与隐私 / WebDAV / 界面改进。

## 版本体系重置

- **版本号 E-0.1.0**：versionCode 自 100 起（> 旧 v1.9.17 的 66，可覆盖安装），此后 E-0.1.1 → 101、E-0.1.2 → 102。
- 升级路径不变：已装 v1.9.11+ 的用户可直接覆盖升级；更早版本仍按旧升级路径处理。

## 下载与画质

- **断网死锁根治**：引擎「跳过」与「真失败」分开记账——三层引擎全被熔断 / 亲和挡掉时不再烧自动重试次数，改为 15 分钟一轮的「断网探测心跳」，网络恢复后首轮即真探成功；退避额度 3→4 次并加长尾（30s / 2min / 15min / 1h），约 78 分钟断网窗口内保持活性。
- **画质实证闸门**：HLS 产物必须实测码率严格优于渐进 mp4 基准才落位，杜绝「走过 HLS 通道」的假升级；测不出 / 损坏文件一律按不达标回退直下 mp4。
- **HLS 路由放宽**：配置 X Cookie（登录态）时，含 HLS 流的视频无条件路由 yt-dlp 一次到位，拉到最高帧率 / 码率档；`--concurrent-fragments 8` 并发分片，「HLS 慢」不再成立。
- **漏报兜底**：FXTwitter 未报 m3u8（hasHls=false 漏报高发）时，yt-dlp 用 `--dump-single-json` 实证探测真实格式表，确有显著更高档才路由，探测失败零损耗直下 mp4。
- **进度回弹修复**：多媒体串行下载进度按「已完成媒体数 + 当前进度」加权，收件箱卡片不再 100%→0% 回弹；yt-dlp 视频 / 音频分段进度同样按段数加权。
- **混合推文补图**：视频+图片混合推文下载视频后自动补齐图片，且补图任务不干扰收件箱聚合进度。
- **源头画质补齐**：图片 URL 强制 `name=orig` 原图；画质升级器对「已确认最优」条目跳过无谓检测。
- **更新检查修复**：GitHub API 被墙（TLS 重置）导致检查失效——直连失败后自动走 gh-proxy.com 镜像前缀，更新检查恢复可用。

## 隐私模式

- **文字一并隐藏**：隐私模式下，收件箱帖子的作者名 / 文案 / @ID，以及详情页的作者 / 文案 / 原始链接，全部以占位符隐藏（连长度都不泄露），不再只藏缩略图。
- **长按 3 秒显示**：按住帖子满 3 秒临时显示隐藏文字（与缩略图同步），松手即恢复；滑动 / 轻触不再误露字。
- 隐私模式下长按不再弹出「复制 / 下载 / 删除」菜单，避免菜单泄露完整链接。

## WebDAV 同步

- **预设层审计修复**：删除不存在的「移动云盘」预设（其无官方 WebDAV）；城通标注需会员；InfiniCloud 地址改正；坚果云描述改为真实月流量口径；数据胶囊地址与「仅 .zip/.prop」限制如实标注。
- **新增「删除已保存配置」**：可按网盘单独清除已保存的账号 / 密码，不牵连其他网盘与全局开关。
- **失败可追溯**：同步历史新增失败原因字段，「最近备份」直接显示「城通 401 认证失败」而非无从查起；删除预设后 providerId 残留自动回退。

## 界面

- **我的页分组精简**：6 组 → 3 组（作品库 / 网络与同步 / 设置），入口全部保留。
- **设置页精简**：「下载行为」并入网络连接页，「存储路径」与「备份与恢复」合成一页。
