# Edqiu v1.7.0

> 覆盖安装说明：本版本与历史版本同包名（com.ed.Edqiu）同签名，直接覆盖安装即可，
> 收件箱数据、Cookie/代理/WebDAV 配置与订阅全部保留，无需卸载重装。

## 新增

- **网盘备份中心整合**：「我的 → 存储与维护」中独立的「网盘备份中心」入口移除，
  功能整体并入「WebDAV 同步」页——新增「网盘备份中心（多网盘直连备份）」入口，
  百度 / 123 / 阿里 / 自定义 WebDAV 直连备份的授权、备份范围与任务状态一处管理。
- **更新弹窗大卡片改版**：检测到新版本时展示「更新内容」（修复/新增说明，来自
  GitHub Release 说明文档，滚动浏览）+ **双下载源**——国内镜像直连（gh-proxy 加速，
  网络不佳推荐）/ GitHub 官方直连，可随时切换重试；另可一键跳转 GitHub Releases
  主页手动下载。镜像源下载完成后仍执行签名自校验，防篡改。
- **开屏跳过按钮**：开屏右上角新增显式「跳过」胶囊入口（整页点按跳过保留），
  引擎就绪即自动进入，不等品牌曝光结束。
- **首次引导动画**：三步引导的图标 / 标题 / 副标题 / 内容错峰淡入上移；页面指示器
  圆点宽度与颜色随翻页位置连续渐变（跟手）。
- **冻结自愈**：新增渲染冻结监视器——检测到界面状态推进而绘制停滞时自动重建窗口，
  画面闪一下即恢复，无需杀进程。

## 修复

- **WebDAV 同步 → 返回链路**：修复浮层打开时侧滑 / 返回键「穿透」浮层、把浮层底下
  的页面逐层弹空的问题——现在浮层打开时返回必先关闭浮层，且正确回到 WebDAV 同步页；
  同步情况浮层底下露出的页面不再错乱。
- **播放器比例形变**：翻页时媒体框比例改为按连续翻页位置跟手插值（旧实现拖拽期
  不形变、过半瞬间硬切）；尺寸缺失的条目不再跳 16:9 兜底估值（消除「每次滑动都
  缩大后再播放」）；视频面 FIT → ZOOM，形变期裁切补位，无黑边忽大忽小。
- **播放器退场定位**：修复连续滑动多条后返回媒体库定位失效——退场先等媒体库定位
  回传终点矩形（媒体库居中改为瞬时，上报提前约 260ms），再执行收缩动画。
- **WebDAV 手动同步**：同步改为应用级任务，退出页面不再中断；退出时提示后台继续，
  回到页面补看结果；输入框内容即时落盘，「立即同步」不再使用旧配置。
- **更新弹窗**：下载源可切换；下载进度卡内显示，关闭弹窗后台继续。

## 其他
