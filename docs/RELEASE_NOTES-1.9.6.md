## 液态玻璃 · 完全体（本轮主线）

- **卡片第一次有了真玻璃**：新增「独立舞台架构」——壁纸锐源单独捕获为采样层，列表卡片直接对它做真磨砂 + 真折射（此前卡片只是半透明贴膜；更早的方案因递归捕获崩溃被封禁，本次从架构上绕开：卡片采样「不含自己的舞台链」，与稳定的底栏同构）。卡片边缘现在真实弯折背后的壁纸与光斑
- **通道级色散（棱镜彩虹）**：卡片与底栏的玻璃边缘开启七光谱采样——不同波长在玻璃缘分离出细腻彩虹色差，角部最强；胶囊反馈额外开启径向深度扭曲（小曲面水珠感）
- **浅色衬托修复**：浅色模式下玻璃折射此前「无素材可采」（背景被白 scrim 抹成均匀白场）——光斑进入采样源、scrim 降档、浅色光斑近全强。浅色的底现在是「彩色渐变团」而非白纸，玻璃明暗可辨
- **壁纸热更新**：换系统壁纸不再需要杀 App——变更即失效重载（广播 + 监听双通道）
- **底栏精修**：取消边缘白线描边（顶光白洗整层移除）、透明度再升档（透光底部更通透）、折射弯折增强；选中 Tab 胶囊从近实底改为透明绿色玻璃洗，内容从胶囊下透出（Apple tab 语言）
- **性能**：全链稳态 jank ≤6.8% / p95 ≤19ms（PLK110 实测，与改造前基线相当）；舞台层为静态纹理，无逐帧成本

## 三页设计重构

- **收件箱**：统计卡与「全部下载」合一（动作与待处理数据同位，无待处理时自动禁用）；随滚动收缩折叠——完整指标卡 ↔ 24dp 进度摘要条，与标题折叠同进度连续变形，统计信息以最密度形态常驻导航区；右上角只留 粘贴/多选
- **我的**：不透明平台色横幅退役（壁纸舞台上的「贴色块」突兀根源）——改为浮在舞台上的身份区：primary 光晕 + 玻璃环头像（保留品牌暖色核心）+ 主题色文字，与统计卡、领域卡同一玻璃世界，无边界线
- **媒体库**：固定栏标题随滚动 20→17sp 收缩（与收件箱同语言）

## 媒体库重复 #1/#2 根治（DB 实证）

- **根因**：文件名里的序号是「下一个可用位」而非「媒体编号」——同一视频重下必然产生 _1/_2 双条目；画质升级走 yt-dlp 时产物还按 `{标题}.mp4` 命名，脱离 App 命名规约
- **三层修复**：①扫描期同媒体合并（同推文 + 同类型 + 时长差 <500ms 判定为同一媒体，保留最高画质文件，删多余行与文件——每轮扫描幂等自愈，实测清掉同时长三份重复、低画质+高画质共存等 4 组）；②HLS 升级产物落库前重命名回规约名；③幽灵行清理（文件被文件管理器删除后 DB 残留 → 扫描即清）
- **扫描 2 倍工作量修复**：扫描根的大小写双拼写让每轮扫描重复处理全部文件（实测每轮 1191 次冗余解析+REPLACE），修后归零
- 多视频推文的真实多片段（时长不同）不受影响

## 全项目稳定性与联动整改（26 项）

- **高危**：「全部下载」此前会把订阅线作品一并按手动下载派发并计入熔断（违背双线隔离，已改只派用户线）；详情页改为实时订阅（后台下完自动刷新，不再停留旧状态可重复点下载）；第三方 API 兜底下载的进度此前不进收件箱（已归并）
- **反馈体系**：玻璃胶囊支持操作按钮——删除后的「撤销」直接在胶囊上点（M3 Snackbar 退役）；下载中心「扫描本地」完成有胶囊提示；WebDAV 撞上自动同步不再报「双向同步完成」假成功（如实提示已跳过）
- **新联动**：Tab 栏红点救活——收件箱有待处理即亮（此前徽标参数从未接线，纯死代码）；订阅作品补删除入口（长按 → 确认 → 进回收站可恢复，此前订阅线无任何删除方式）；我的页与收件箱统计口径统一
- **回收站 30 天保留期实装**：启动自动清理过期归档（此前文案承诺 30 天、实际永久保留）
- **防重入**：下载中心扫描、订阅「立即检测」与后台轮询互斥
- **口径与文案**：回收站/订阅假承诺修正（「自动入库下载」→「自动入库，点按下载」等 3 处）
- **死代码与遗留**：pendingCount 死链、predictive_back 死键、Screen.Player 死路由、Titanic 源码库全家、download_tasks 死恢复链、死字符串/死 DAO 等 10+ 项清理；吞错处补日志；cookie 路径日志门控 debug
- release/R8 构建链验证健康（此前从未验过混淆构建）
