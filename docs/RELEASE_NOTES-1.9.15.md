# v1.9.15 更新内容

**主题：底部 Tab 栏重设计——动态胶囊导航**　versionCode 64

## 重设计（外壳尺寸不变）

- **布局语言从「三列同构」改为「动态胶囊导航」**：
  - **选中项**：滑动胶囊内「实底图标 + 文字」横排聚合——选中态的信息密度与视觉重量显著高于未选中态，胶囊滑到哪、哪一项就展开为完整标识
  - **未选项**：纯 24dp 大图标居中，退为环境元素——去掉旧版「图标+迷你文字」的拥挤与选中时图标的上下跳位
- **三枚图标全部换新**：轮廓版（未选中）/ 实底版（选中）成对切换（收件箱 / 媒体库 / 人像）——实底图形是「已进入」的强语义，替代旧版的颜色+缩放微调
- **文字样式**：11.5sp Bold + 字间距 0.3sp，主题色跟随
- 外壳悬浮胶囊 50dp、三等分点击区、红色徽标、按压弹性全部保留

## 兼容性

- 数据库版本不变（v15/v11），覆盖安装数据全保留；签名不变（v1.9.11+ 可直接覆盖）
- Android 7.0+（API 24）· 仅 arm64-v8a
